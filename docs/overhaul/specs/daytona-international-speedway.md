# Daytona International Speedway

Type: racetrack. Pipeline path: fallback.

Type rule: Banking, main grandstand, pit road. Frame on the grandstand side so the track doesn't read as an empty green pill.

## Identifying features

| # | Feature | Reference |
|---|---|---|
| 1 | Tri-oval track, 2.5 miles, with high banking in the four turns | NAIP aerial |
| 2 | Main grandstand along the front stretch with five stacked levels and glass suites (the Daytona Rising frontstretch) | #17 (Daytona-International-Speedway-WorldCenterofRacing-Lettering.jpg) |
| 3 | Checker-pattern seat colors in the frontstretch grandstand | #17 (Daytona-International-Speedway-WorldCenterofRacing-Lettering.jpg) |
| 4 | Pit road along the front stretch, separated by a grass strip | #5 (2022 24 Hours of Daytona Pit Lane.jpg) |
| 5 | Infield with Lake Lloyd and the garage area | NAIP aerial |

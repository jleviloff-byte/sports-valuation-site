# Fenway Park

Type: baseball. Pipeline path: photo.

Type rule: Dirt infield, grass outfield, foul lines; outfield wall at the park's real asymmetric shape and height; stands wrap foul pole to foul pole behind home plate. Never a symmetric bowl.
